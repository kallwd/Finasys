# Finasys

Finasys 是本機專用的台股研究與虛擬交易系統。完整原始碼、模型環境、SQLite 模擬帳本與一鍵啟動檔都放在同一個專案資料夾中。

## 固定邊界

- 起始虛擬資金：NT$200,000。
- 最低現金保留：NT$40,000；策略最多使用 NT$160,000。
- 冒險部位總上限 NT$40,000；穩健部位總上限 NT$120,000。
- 單一標的與單筆交易上限 NT$40,000，最多 5 個持倉。
- 買進後立即鎖住現金；賣出款到台股交易日 T+2 才可重新使用。
- 不融資、不融券、不做期貨、不使用槓桿。
- 不連接券商、不讀真實持倉，也沒有真實下單端點。
- 服務只綁定 `127.0.0.1`，外部電腦無法連入。

## 每日分析

開盤前把候選標的分成「冒險」、「穩健」、「別碰」三類，優先研究科技巨頭、AI／半導體生態、電子設計、AI 基礎設施、通訊與機器人。穩健類的約 7% 指年化研究目標，不是報酬保證。

完整的不可作弊、停損、成交與 T+2 規則請看 `STRATEGY_POLICY.md`。

## 一鍵啟動

在專案資料夾內雙擊 `啟動 Finasys.vbs`。它會在背景啟動本機服務並開啟：

`http://127.0.0.1:17888/`

若需要手動啟動：

```powershell
.\scripts\start_trader.ps1
```

## FinLab 資料登入

在首頁按「開啟 FinLab 登入」，只會啟動 FinLab 官方瀏覽器登入。完成後回首頁按「重新整理」。不要把 FinLab token 貼進聊天或寫進原始碼。

FinLab 是資料與量化研究來源；產品名稱與帳本均為 Finasys。

## 目前功能

- 非技術操作 UI。
- 台北時間、台股開盤／收盤、週末與休市判斷。
- scikit-learn、LightGBM、hmmlearn 套件狀態與合成資料自我檢查。
- 200,000 元 SQLite 模擬帳本與保守 T+2 結算。
- 零股目標配置預覽，不會送出真實委託。
- API 文件：`http://127.0.0.1:17888/docs`。

## 重要狀態

模型自我檢查使用合成資料，只驗證程式可運作，不能視為預測績效。FinLab 尚未登入或當日資料不足時，系統必須輸出「不交易」，不得猜測或補造資料。

Codex 額度歸零時停止新的 AI 分析與開發，不會自行購買或重設額度；已安裝的本機 UI 與帳本仍可開啟。
